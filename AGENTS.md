# Project Rules

- Treat this folder as the project root.
- Use Git for project management in this repository.
- Make small, meaningful commits as work progresses, especially after a clear milestone or whenever a task is getting close to a logical stopping point.
- Do not push to any remote unless the user explicitly asks.
- Keep generated files and local environment folders out of version control.
- When starting new work, check the current repo state first so we do not overwrite user changes.
